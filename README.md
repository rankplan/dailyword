# DailyWord

One word a day, in your language. A multi-language fork of Taeglich Wort.

Pick a language at the top: Deutsch, English, Italiano, Espanol, Francais.
The same day shows the same concept in every language, with forms, two
examples in context and a six-question fill-in test.

Day 1 is 21 November 2026. The set runs for 365 days.

Files: index.html (the app), data-de.js, data-en.js, data-it.js, data-es.js
and data-fr.js (the word data), manifest.webmanifest and sw.js (the PWA
pieces), and the DailyWord logo icons.

Static site: serve this folder with any web server, for example
python3 -m http.server
